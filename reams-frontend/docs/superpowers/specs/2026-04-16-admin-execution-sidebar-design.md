# Admin Execution Sidebar Design

## Goal

将管理员首页右侧区域从“排行榜与提示”为主，调整为“待办执行与近期动态”为主，让管理员进入页面后优先看到需要处理的审核事项，并保留中间区域的经营分析图表。

## Scope

本次只调整管理员首页 `src/views/admin/Admin.vue` 的信息架构与交互，不修改现有路由权限，不新增独立页面。交易相关快捷入口继续走交易管理列表页，而不是直接跳交易详情页。

## Current Context

- 管理员首页已经具备完整的中间经营分析区：成交趋势、价格段分析、城市对比、区域分布。
- 右侧当前为四个偏展示型模块：
  - 城市成交 Top 5
  - 头部中介 Top 5
  - 交易流程分布
  - 经营提示
- 现有路由中本次设计会用到的管理员入口：
  - ` /layout/audit/house `
  - ` /layout/user/staff `
  - ` /layout/transaction/manage `
- 用户已经明确：
  - 右侧四块全部替换
  - 待办优先级中“房源审核”排第一
  - 交易快捷入口跳交易管理列表页，不直接跳交易详情页

## Design Summary

右侧四个模块整体改为“管理员执行台”：

1. 房源审核待办
2. 中介注册审核
3. 最近成交动态
4. 快捷处理

中间主栏图表区域保持不变，以维持管理端的经营分析能力；右栏改成任务导向的信息区，形成“中间看经营，右侧做执行”的布局分工。

## Right Sidebar Modules

### 1. 房源审核待办

这是右侧第一优先模块。

展示内容：

- 待审核房源总数
- 最近 3 到 5 条待审核房源摘要
- 每条包含：
  - 房源标题
  - 所属区域
  - 提交时间
  - 发布人或中介名
- 模块底部提供 “去审核房源” 按钮

点击行为：

- 跳转到 ` /layout/audit/house `

视觉定位：

- 使用比普通卡片更醒目的样式
- 保持与 `AgentWorkspace.vue` 一致的圆角白卡、轻阴影和浅绿色调
- 通过数量徽标或强调条突出“待处理数量”

### 2. 中介注册审核

这是右侧第二优先模块。

展示内容：

- 待审核中介数量
- 最近几条待审核申请
- 每条包含：
  - 申请人姓名
  - 手机号或账号
  - 申请时间
  - 当前审核状态

点击行为：

- 模块底部按钮跳转到 ` /layout/user/staff `

说明：

- 当前系统未确认是否存在独立“中介注册审核页”，因此优先复用现有员工管理页作为承接入口。

### 3. 最近成交动态

这是右侧第三模块，用于帮助管理员快速感知近期交易完成情况。

展示内容：

- 最近成交总量摘要，例如近 7 天成交几单
- 最近 3 到 5 条成交记录
- 每条包含：
  - 交易编号
  - 房源标题
  - 成交时间
  - 成交金额
  - 关联中介或客户简要信息

点击行为：

- 本模块不直接跳交易详情
- 如需查看完整交易链路，使用下方“交易管理”快捷入口进入列表页

说明：

- 这样可以与用户指定的“交易入口走列表页”保持一致
- 同时避免在右侧出现多个跳转语义不同的交易入口

### 4. 快捷处理

这是右侧第四模块，承接常用后台动作。

保留与新增：

- 保留现有：
  - 房源审核
  - 员工管理
- 新增：
  - 交易记录

点击行为：

- 房源审核：` /layout/audit/house `
- 员工管理：` /layout/user/staff `
- 交易记录：` /layout/transaction/manage `

说明：

- 这里不连接交易详情页
- “交易记录”快捷入口实际进入交易管理列表页 `TransactionManage.vue`

## Data Strategy

### Preferred Data Source

优先复用管理员首页当前使用的 `/admin/dashboard` 接口。

### New Data Expectations

如果后端支持，管理员首页最好补充以下列表型字段：

- 最近待审核房源列表
- 最近待审核中介注册列表
- 最近成交记录列表

### Frontend Compatibility Rule

前端实现必须兼容两种情况：

1. 接口已返回列表数据
   - 展示真实列表
2. 接口未返回列表数据
   - 使用已有统计字段展示数量
   - 列表区域展示空状态文案，而不是伪造不可追溯的数据

这样可以先完成页面结构升级，而不会把前端绑定到尚未确定的后端字段上。

## Interaction Rules

- 房源审核待办优先显示在最顶部
- 右侧信息全部以“最近要处理什么”为导向
- 排行榜类模块完全移除
- 不在右栏新增复杂筛选器，避免管理员首页负担过重
- 快捷入口保持一键直达，不添加中间弹窗

## Layout and Styling

- 延续当前管理员页已经建立的视觉体系
- 对齐 `AgentWorkspace.vue` 的视觉语言：
  - 渐变浅绿背景
  - 白色大圆角卡片
  - 轻阴影
  - 胶囊按钮
  - 简洁信息层级
- “房源审核待办”卡片应比其他右栏卡片更强调优先级
- “最近成交动态”采用列表型卡片而不是排行榜样式

## Error Handling and Empty States

每个新模块都需要独立空状态：

- 没有待审核房源：显示“当前没有待审核房源”
- 没有待审核中介：显示“当前没有待审核中介申请”
- 没有最近成交：显示“近期暂无成交记录”

如果接口失败：

- 沿用页面顶部已有错误横幅
- 右栏各模块不额外抛异常，只展示空内容或保底文案

## Testing and Verification

实现完成后需要验证：

1. 管理员首页可正常编译
2. 房源审核、员工管理、交易记录三个快捷入口跳转正确
3. 无列表数据时页面能正常显示空状态
4. 有列表数据时右栏能稳定渲染
5. 页面在桌面端与移动端都不会出现布局塌陷

## Out of Scope

以下内容不在本次范围内：

- 新增后端接口
- 修改交易详情页行为
- 新建独立中介审核页
- 调整中间图表分析模块的业务逻辑
